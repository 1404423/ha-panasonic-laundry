# Security

This integration stores OAuth tokens for a Panasonic account in the Home Assistant config entry. If you think a token leaked
(a pasted log, a backup), change your Panasonic password and remove the integration.

Please do **not** post tokens, authorization codes, `appliance_id` values or full API responses in issues. Report a security
problem privately through GitHub's "Report a vulnerability" (Security tab) instead of a public issue.
